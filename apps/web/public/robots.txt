# NEVER Disallow a path that also carries an X-Robots-Tag / meta noindex.
# Google must CRAWL a page to SEE its noindex. Blocking it instead freezes the
# URL in the index as "Indexada aunque bloqueada por robots.txt" forever.
# Choose one: block for crawl budget, OR noindex to de-index. Never both.
# Cross-check any new Disallow against apps/web/public/_headers.

# /rides/ and /drivers/ are deliberately NOT Disallowed (changed 2026-09-16).
# They carry `X-Robots-Tag: noindex, nofollow` in public/_headers, but a noindex
# on a robots-BLOCKED URL is invisible: Googlebot never fetches the page, so it
# never sees the header, and the URL stays indexed from link discovery alone.
# That is what produced GSC "Indexada aunque bloqueada por robots.txt" = 97.
# Unblocked + noindex lets Googlebot fetch, read the noindex, and DROP them —
# the exact pattern already documented for /feed below. Do NOT re-add these
# Disallow lines: doing so freezes the URLs in the index permanently.
# Filter query params on /concerts are UX-only. seoPrerender (§B, index.ts
# ~:4185) already answers bot requests for `/concerts?<anything>` with a 301 to
# the canonical `/concerts`.
#
# The `Disallow: /concerts?` lines were REMOVED on 2026-09-16 because they made
# that 301 unreachable and were actively harmful:
#   - Blocked-but-linked URLs are never crawled, so Google can never see the
#     301 that would consolidate them. They accumulate in the index frontier
#     forever instead. Filter anchors are emitted on 8,000+ prerendered pages,
#     so the combinatorial `?city=&artist=&tab=` space is what drove GSC
#     "Bloqueada por robots.txt" to 8,432.
#   - Verified live 2026-09-16: Googlebot on /concerts?city=madrid received
#     HTTP 200 with no X-SEO-Prerender header — the asset layer answered before
#     the Worker ran. Fixed via `assets.run_worker_first` in wrangler.jsonc.
# Letting Googlebot CRAWL these and receive the 301 is what actually removes
# them. Do NOT re-add the Disallow lines.
# Phase 1+2+3 social surfaces — personal/dynamic, never indexable.
# /memorias/:id is intentionally NOT blocked: public memories with
# visibility="public" remain indexable as social-proof landing pages.
# NOTE: /memorias (index) has noindex in MemoriasPage.tsx — no Disallow needed here.
# robots.txt does NOT support $ regex anchors — Disallow: /memorias$ would be
# treated as a literal path and block nothing useful.
# /feed was REMOVED as a feature (2026-08-19). It is intentionally NOT listed
# here: a noindex on a robots-blocked URL is invisible to Google (SKILL §AD.6),
# so the URL would linger as "Indexada aunque bloqueada". Unblocked + noindex
# (public/_headers) lets Googlebot fetch it, see the noindex and drop it.
Disallow: /crew
Disallow: /squads
Disallow: /mensajes
